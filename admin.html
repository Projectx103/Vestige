One-time setup: add these two blocks inside match /databases/{database}/documents in your Firestore Rules, then click Publish: 
match /batches/{batchId} {
  allow read: if true;
  allow write: if isAdmin();
}
match /counters/{id} {
  allow read, write: if isAdmin();
}

Batch Settings

Set your defaults once so every new batch starts ready — then use the tools below to keep things tidy.

New batch defaults

Use {n} for the Batch Number. Leave the template empty to type each name yourself.

Suggest the next Batch Number
New batches start with the next free number (highest existing number + 1). You can still change it.
Pre-fill bidding dates
New batches start with Bidding Start and End already filled in from the values below.

Behavior

Ask before closing or reactivating a batch
Shows a confirmation whenever a status is changed from Batch Search.
Close batches automatically when bidding ends
Checked each time you open the admin page. Ended Active batches are closed and their items are released. (Runs when you open the page, not in the background.)

Rewrites the live copy that home.html reads from your newest Active batch. Use it if the home page ever looks out of date.

Rebuilds the Control No. counter and the Batch Number / Name lookup from your saved batches. Safe to run; it also reports any duplicates.
Download backup
Saves all batches, the counter and these settings as a JSON file.
